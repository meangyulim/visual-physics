# 그림으로 이해하는 고등 물리 — 물리학Ⅰ·Ⅱ

고등학교 물리학Ⅰ·Ⅱ(2015 개정 교육과정) 핵심 개념을 **그림 · 인터랙티브 시뮬레이션 · 바로 풀어 보는 문제**로 이해하는 정적 웹사이트입니다. 폰·태블릿·PC 어디서나 볼 수 있고, 다크 모드를 지원합니다.

- 개념: 단원별 그림 개념 카드(질문 → 그림 → 설명 → 공식·유도 → 비교표 → 확인 예제 → 핵심 포인트)
- 직접 해보기: 운동 그래프, 충돌, 역학적 에너지, 열역학 과정, 빛 시계, 보어 모형, 전기장·자기장, 전자기 유도, 파동·굴절·간섭, 광전 효과, 포물선 운동, 단진자, 축전기, RLC 공명, 도플러 효과, 이중 슬릿, 볼록 렌즈 등
- 문제: 개념마다 선택형 개념 체크(해설), 단원별 OX 퀴즈와 도전 문제(단계별 풀이)
- 실전 연결: 1등급 사고법, 유형별 풀이 흐름, 기출 연결, 고난도 문제 패턴, 대학 물리 연결

## 구조
```
index.html          홈(단원 목록·개념 검색)
u/<단원>.html        단원 페이지 13개 (I1~III2: 물리학Ⅰ, A1~C2: 물리학Ⅱ)
assets/css          theme.css(색 토큰) · site.css · sim.css
assets/js           site.js(탭·퀴즈·그림 확대·테마) · simkit.js · sims/*.js(시뮬레이션)
assets/img          그림(WebP)
assets/katex        수식 글꼴·스타일(KaTeX, MIT)
```
빌드 도구 없이 그대로 GitHub Pages로 배포됩니다. 수식은 미리 렌더링되어 있어 자바스크립트 없이도 보입니다.

## 저작권
설명·그림·문제·시뮬레이션은 직접 제작한 교육용 자료입니다. 기출 연결의 문항 번호는 한국교육과정평가원 시험 문항을 가리키는 참고 표기이며 문항 원문은 포함하지 않습니다. 수식 렌더링에 [KaTeX](https://katex.org)(MIT), 글꼴에 [Pretendard](https://github.com/orioncactus/pretendard)(OFL)를 사용합니다.
